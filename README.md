# 작탁을 만들자!

리치 마작 입문자를 위한 모바일 앱 느낌의 정적 PWA 학습 앱입니다.

## 주요 기능

- 기본 규칙: 자리, 차례, 화료 조건, 멘젠과 역의 관계를 카드로 학습
- 마작 패 소개: 만수패, 통수패, 삭수패, 자패, 적도라 확인
- 심화 규칙: 입문 역을 단계별로 학습
- 퀴즈: 룰, 패, 역 판단 문제 풀이
- 점수: 판수와 부수로 대략 점수 감각 확인
- 게임하기: 전국 마장 정보(지역 필터)

## 구성

- 홈 대시보드: **데일리 퀴즈**(날짜마다 다른 14장 + 1문항), 파트별 진도, 빠른 학습 카드
- 기본 규칙: 작탁 자리, 한 판 진행, 기본 용어
- 마작 패 소개: 만수패, 통수패, 삭수패, 자패, 적도라를 실제 패 이미지로 학습
- 심화 규칙: 1판 필수 역과 2판 이상 자주 쓰는 역을 단계별 카드로 학습
- 퀴즈: 룰·역 판단 문제 (손패 이미지는 문항에 따라 표시)
- 점수: 판수와 부수 슬라이더로 대략적인 점수 감각 확인
- 게임하기: `parlors.js`에 마장 항목 추가 (`region`, `name`, `address` 등)

## 실행

`index.html`을 브라우저에서 열면 바로 실행됩니다. 스마트폰은 최대 430px, 태블릿(600px~)은 최대 720px, 큰 화면(900px~)은 최대 960px까지 넓게 표시됩니다.

로컬 서버로 확인하려면 프로젝트 폴더에서 아래 중 하나를 실행해도 됩니다.

```bash
python -m http.server 5500
```

브라우저에서 `http://localhost:5500`으로 접속합니다.

## 최근 변경

- 기본 규칙 뷰 추가: 작탁 자리 다이어그램, 진행 단계 카드, 기본 용어(동풍전·국·텐파이·유국 포함)
- 홈 데일리 퀴즈: 28종 손패 풀을 날짜 해시로 순환
- PPT 보강: 후로·리치·노텐·대기·도라·친자 점수 안내, 풍패/삼원패 분리, 요구패 N장 퀴즈
- 「리치마작 강좌」PDF 1장(온라인편 기초) 반영: 호출 우선순위, 도라 표시 예시, 본장·핑후 조건, 리치 규칙, 퀴즈 보강
- 하단 탭: **게임하기** · **점수** (홈은 플로팅 버튼·홈 카드)
- 게임하기: `parlors.js`에 전국 마장 목록 추가·지역 필터
- 심화 규칙 상단에 「역이란?」 안내 카드 추가
- 퀴즈에 `type` 필드와 룰 관련 문항 추가
