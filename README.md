# 작탁을 만들자!

리치마작 입문자를 위한 모바일 앱 느낌의 정적 웹 학습 앱입니다.

## 구성

- 패 익히기: 만수, 통수, 삭수, 자패, 적도라
- 역 단계: 역을 범주별 단계로 학습
- 퀴즈: 손패를 보고 기본 역 판단
- 점수: 판수와 부수로 대략 점수 감각 확인

## 실행

`index.html`을 브라우저에서 열면 바로 실행됩니다.

## 이미지 출처

마작패 이미지는 Wikimedia Commons의 Cangjie6 및 기여자 SVG 이미지를 사용합니다.
라이선스는 각 파일 페이지의 CC BY-SA 4.0 조건을 따릅니다.
